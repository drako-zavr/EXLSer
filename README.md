# EXLSer

Как запустить приложение:

1. Нажать на зеленую кнопку <>Code справа сверху
2. Нажать Download ZIP
3. Распаковать ZIP в любое удобное мето
4. В папке EXLSer-main распаковать XLSer.zip
5. Правой кнопкой мыши кликнуть по папке(EXLSer-main), в которой находится XLSer.app
6. Выбрать "Новый терминал по адресу папки"
7. В открывшемся окне ввести xattr -d com.apple.quarantine XLSer.app
8. Нажать Enter
9. Закрыть окно после исполнения команды (появится новая строчка)
10. Запустить приложение
